# Infographic Skill - 小红书爆款信息图生成技能

> 将复杂专业知识转化为高密度、视觉化的小红书爆款干货内容

![GitHub License](https://img.shields.io/github/license/haokuang/infographic-skill)
![Claude Code](https://img.shields.io/badge/Claude%20Code-Skill-blue)

---

## 🎯 功能特点

- **8 种视觉风格**：从复古波普到实验室蓝图，满足不同主题需求
- **高密度信息**：每张图包含 6-7 个模块，拒绝空洞内容
- **自动化生成**：从内容策划到图片生成一站式完成
- **4K 高清输出**：支持 3584×4800 分辨率，专业印刷品质

---

## 🎨 8 种风格

| 编号 | 风格名称 | 视觉特点 | 适用场景 |
|------|----------|----------|----------|
| 1️⃣ | **打印热敏纸风** | 收据/票据美学，现代新拟物风格，3D 粘土图标 | 清单、教程、步骤指南 |
| 2️⃣ | **档案风** | 案件档案板/侦探风格，混合媒体剪贴画 | 深度分析、案例研究 |
| 3️⃣ | **复古风** | 70 年代瑞士网格系统，粗黑描边 | 对比指南、品牌评测 |
| 4️⃣ | **手帐风** | 复古剪贴簿/手绘日志，撕裂纸张元素 | 生活技巧、经验分享 |
| 5️⃣ | **高密度信息大图** | 实验室精密手册感，坐标系统 | 技术参数、专业数据 |
| 6️⃣ | **票据风** | 剧院票券风格，"五幕剧"叙事结构 | 故事性内容、发展历程 |
| 7️⃣ | **色块风** | Y2K 复古未来主义，酸性霓虹色彩 | 科技主题、潮流内容 |
| 8️⃣ | **文件夹风格** | 新拟物文具风，剪贴板 + 文件夹 + 标签 | 办公技巧、知识整理 |

## 📦 安装方法

### 方法 1: 克隆仓库

```bash
git clone https://github.com/haokuang/infographic-skill.git
cp -r infographic-skill ~/.claude/skills/
```

### 方法 2: 手动下载

1. 下载 [`SKILL.md`](./SKILL.md) 文件
2. 创建目录 `~/.claude/skills/infographic/`
3. 将 `SKILL.md` 放入该目录

---

## ⚙️ 配置

### 环境变量设置

在 `~/.claude/settings.json` 中添加：

```json
{
  "env": {
    "TUZI_API_KEY": "your-tuzi-api-key"
  }
}
```

或者在终端中设置：

```bash
export TUZI_API_KEY="your-tuzi-api-key"
```

### API 配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| Base URL | `https://api.tu-zi.com` | Tuzi API 地址 |
| 默认模型 | `gemini-3-pro-image-preview-4k` | 图片生成模型 |
| 默认尺寸 | `3x4` (3584×4800) | 小红书竖版比例 |
| 输出目录 | `~/Documents/trae_projects/xhs-images/` | 图片保存位置 |

## 🚀 使用方式

### 基础使用

在 Claude Code 中输入：

```
/infographic
```

### 完整流程

```
1. 用户输入 /infographic
   ↓
2. 选择 8 种风格之一
   ↓
3. 提供主题、描述、图片数量
   ↓
4. AI 生成高密度内容（6-7 模块）
   ↓
5. 用户确认内容
   ↓
6. 调用 API 生成图片
   ↓
7. 保存到本地目录
```

## 📋 输出示例

### 内容结构模板

```markdown
## 图片 1：咖啡豆品种选择指南

**主标题：** 咖啡豆品种选择指南
**副标题：** 6 大维度全面解析咖啡豆

### 模块内容（6-7 个模块）：

**[品种分类]** - 品牌/选项类
- 阿拉比卡：[图标] 酸甜平衡，适合手冲
- 罗布斯塔：[图标] 苦味重，适合意式
- 利比里卡：[图标] 特殊风味，小众选择

**[参数标准]** - 数值阶梯类
- 海拔 800m 以下：❌ 商业级
- 海拔 800-1200m：✓ 优质级
- 海拔 1200m 以上：👑 精品级

**[场景对比]** - 场景对比类
- 手冲：推荐浅烘阿拉比卡
- 意式：推荐深烘拼配豆

**[识别技巧]** - 识别方法类
- 看：豆形完整，色泽均匀
- 闻：无霉味，有清香

**[对比表格]** - 参数对比类
[表格形式展示各品种参数]

**[避坑提醒]** - 注意事项类
⚠️ 避坑清单：
- ❌ 过度追求产地故事
- ❌ 忽略烘焙日期

**[快速总结]** - 要点速览
💡 一句话总结：选对品种比选对产地更重要
```

## 🔧 故障排除

### 问题 1: API Key 无效

```bash
# 检查环境变量是否设置
echo $TUZI_API_KEY

# 在 Claude Code 中验证 settings.json
cat ~/.claude/settings.json | jq .env
```

### 问题 2: 图片生成失败

```bash
# 检查 API 连接
curl -H "Authorization: Bearer $TUZI_API_KEY" \
  https://api.tu-zi.com/v1/images/generations
```

### 问题 3: 输出目录不存在

```bash
# 创建输出目录
mkdir -p ~/Documents/trae_projects/xhs-images/
```
